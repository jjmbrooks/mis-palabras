# Cómo contribuir

¡Gracias por ayudar! Mis Palabras está en etapa de diseño.

- **Documentación:** todo el diseño y la evidencia viven como Markdown en `docs/`. Propón cambios con un pull request o abre un issue.
- **Corrección de evidencia:** si una afirmación no está bien sustentada o una fuente está mal citada, usa la plantilla de issue «Corrección de evidencia» e incluye la fuente que la corrige.
- **Privacidad:** nunca incluyas datos personales, nombres reales de niños, capturas con datos reales, secretos ni llaves.
- **Tono:** respetuoso; recuerda que esto lo usarán familias y personas neurodivergentes.
