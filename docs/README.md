## Cómo proponer correcciones

- **Issue:** abre un issue en GitHub indicando la sección, el problema (cita incorrecta, afirmación sin respaldo, fuente nueva) y la referencia completa con DOI o URL.
- **Pull request:** edita el archivo `.md` y explica el cambio en la descripción. Toda afirmación nueva debe citar una fuente verificable (DOI, PubMed o página del editor).
- No incluyas datos personales de niños, familias ni alumnos en issues, PR o ejemplos.
