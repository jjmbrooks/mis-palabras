# Mis Palabras

App web gratuita y de código abierto para practicar lectura con mazos de cartas de palabras de varias temáticas, pensada para que la usen familias.

> **Estado:** en definición. Todavía no hay código; la mecánica se está diseñando. La documentación de diseño y evidencia vivirá en [`docs/`](docs/).

## Requisitos de privacidad (no negociables)

1. **Cada familia tiene su propia cuenta.**
2. **Nadie ve los datos de otra familia**, ni siquiera el administrador del servicio.
3. **El niño se registra con un apodo**, nunca con su nombre real.
4. **La familia puede exportar o borrar todos sus datos** cuando quiera.
5. **Sin analítica de terceros.**
6. **Datos de uso mínimos:** solo la palabra, si fue acierto o error, y la fecha.

## Reglas del repositorio

Este repositorio es público: **cero secretos, llaves, credenciales ni datos reales** en el código, los documentos o los issues.
